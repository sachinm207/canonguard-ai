Everything you need to understand cinematic continuity, studio workflows, and engine concepts

🎬 1. How Lore Works: Previous Data vs. Current Script

The Previous Data (Franchise Canon Archive): In major studios (Marvel, Lucasfilm, DC), universes span 30–80 years of history. "Lore Keepers" maintain 800-page Franchise Bibles. In CanonGuard AI, past movies (The ChronoVerse 1900–2080) are pre-loaded into ClickHouse tables tracking character lifespans, destroyed artifacts, and planetary rules.

What "Current" Means: Screenwriters write movies scene-by-scene. "Current" refers to the active scene currently being typed today (e.g., Scene 14 in 1982 Berlin). CanonGuard verifies in real-time if this single new scene accidentally contradicts 40 years of past established history.

🖥️ 2. Screenplay Studio Elements Explained

  • Cold War Requiem.fountain: The file name of the script. .fountain is the open-source plaintext standard used in Hollywood screenwriting (like Markdown for screenwriters).
  • Setting: Berlin Safehouse | Scene Year: 1982: The scene heading ("Slugline"). It gives the engine the temporal year (1982) and place to evaluate whether characters or weapons can legally exist there.
  • Auto-Lint Active (350ms): Like a programming code linter or Grammarly, the background agent waits 350ms after you stop typing, queries ClickHouse in < 1ms, and automatically draws red squiggly underlines under continuity mistakes.
  • Pre-seeded Demo Traps: In software QA, a "trap" is an intentional test case. The 3 buttons load famous continuity errors (stasis paradox, destroyed relic, toxic air) with 1 click so you can see sub-millisecond detection in action.
